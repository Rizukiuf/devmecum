## Sekilas

Tulis kodenya, simpan, lalu jalankan lewat interpreter; atau coba baris demi baris di mode interaktif. Begitulah cara kerja Python, bahasa pemrograman yang mendukung gaya berorientasi objek, prosedural, dan fungsional. Ia berjalan di Unix (termasuk Linux dan macOS) maupun Windows, dengan sintaks yang sederhana dan konsisten serta pustaka standar yang luas.

## Untuk apa dan siapa pemakainya

Python dipakai di banyak bidang. Halaman About di python.org menyebut web dan internet, akses database, GUI desktop, komputasi ilmiah, pendidikan, pemrograman jaringan, serta pengembangan perangkat lunak dan game.

Untuk contoh proyek nyata, FAQ resmi menyebut Mailman (pengelola milis) dan Zope (application server) yang ditulis dengan Python. Anggap keduanya sekadar contoh dari FAQ, bukan daftar pemakai terkini.

FAQ yang sama menyarankan Python sebagai bahasa pertama. Alasannya, sintaksnya sederhana dan konsisten, jadi kamu bisa fokus memecahkan masalah, dan ada interpreter interaktif untuk coba-coba.

## Keunggulan dan kelemahan

<ProsCons>
<Fragment slot="keunggulan">

- Pustaka standarnya mencakup regex, Unicode, HTTP, SMTP, unit test, logging, dan socket.
- Kalau pustaka standar belum cukup, ada PyPI: lebih dari 940 ribu proyek per 16 November 2026 (pypi.org).
- Interpreter tersedia di Unix, macOS, dan Windows, dan FAQ resmi menyebut Python portabel.
- Mode interaktif dan sintaks yang konsisten membuat FAQ resmi merekomendasikannya untuk pemula.
- Modul `asyncio` tersedia untuk kode jaringan dan pekerjaan I/O-bound.

</Fragment>
<Fragment slot="kelemahan">

- Di build standar, GIL (global interpreter lock) membuat hanya satu thread yang menjalankan bytecode Python pada satu waktu. Akibatnya, pekerjaan yang berat di CPU tidak bisa dibagi paralel antar-thread.
- Anotasi tipe tidak ditegakkan saat runtime. Go adalah bahasa statically typed; di Python kamu perlu type checker terpisah.
- Python dijalankan lewat interpreter, sedangkan Go dikompilasi ke kode mesin native. Soal kecepatan, ukur sendiri dengan benchmark untuk beban kerjamu.
- Antarversi ada API yang dihapus. Python 3.15 menghapus, misalnya, `glob.glob0()`, `glob.glob1()`, dan modul `sre_*`, jadi kode lama mungkin perlu diperbarui.
- Dukungan per seri terbatas: 3.15 didukung sampai Oktober 2031, dan 3.10 sudah berakhir. Proyek jangka panjang perlu rencana pindah versi.

</Fragment>
</ProsCons>

## Kapan dipakai, kapan tidak

Python cocok untuk:

- Pekerjaan yang terbantu pustaka standar dan PyPI, seperti memproses teks dengan regex, berkomunikasi lewat HTTP, dan menulis unit test.
- Layanan jaringan yang lebih banyak menunggu I/O daripada menghitung, dengan `asyncio`.
- Belajar pemrograman dari nol.

Pikirkan ulang kalau:

- Kamu ingin beberapa thread menjalankan bytecode Python bersamaan. Build standar tidak mengizinkannya karena GIL.
- Kamu butuh jaminan tipe saat runtime tanpa alat tambahan.
- Proyekmu masih bergantung pada versi yang sudah end-of-life, seperti 3.10.

<VersionNote version="3.13">
Build free-threaded (tanpa GIL) tersedia sejak 3.13 dan resmi didukung sejak 3.14. Ada harganya: dokumentasi resmi menyebut overhead untuk kode satu-thread sekitar 1% di macOS aarch64 dan sekitar 8% di Linux x86-64, dan pemakaian memori biasanya lebih tinggi. Paket dengan extension module yang belum siap bisa menyalakan GIL kembali.
</VersionNote>

## Contoh minimal

Simpan kode ini sebagai `fibonacci.py`. Programnya mencetak deret Fibonacci yang nilainya di bawah 10.

```python title="fibonacci.py"
a, b = 0, 1
while a < 10:
    print(a)
    a, b = b, a + b
```

Jalankan dengan `python fibonacci.py`. Kalau `python` tidak dikenal, di Windows coba `py`. Di Unix, interpreter Python 3 secara bawaan tidak dipasang dengan nama `python`; biasanya namanya mengikuti versi, misalnya `python3.15`.

```text

1
1
2
3
5
8
```

## Konsep kunci

- **Interpreter:** program yang membaca lalu menjalankan kode Python, termasuk mode interaktif dengan prompt `>>>`.
- **Type hints:** anotasi tipe yang dibaca alat seperti type checker, bukan ditegakkan saat runtime.
- **Pustaka standar:** modul bawaan Python, misalnya untuk regex, HTTP, dan logging.
- **PyPI dan pip:** PyPI adalah registri paket pihak ketiga, dan pip alat untuk memasangnya.
- **Virtual environment (`venv`):** folder berisi interpreter dan paket yang terpisah untuk satu proyek.
- **GIL:** pembatas di CPython yang hanya mengizinkan satu thread mengeksekusi bytecode Python pada satu waktu.
- **Free-threaded build:** build CPython tanpa GIL, tersedia sejak 3.13.
- **asyncio:** modul untuk konkurensi, ditulis dengan sintaks `async` dan `await`.
- **Lazy imports:** fitur baru di 3.15 (PEP 810): modul yang diimpor dengan kata kunci `lazy` secara eksplisit.
- **PEP (Python Enhancement Proposal):** naskah desain yang menjelaskan fitur baru atau memberi informasi bagi komunitas.

## Prasyarat dan langkah berikutnya

Tidak ada prasyarat; Python bisa jadi bahasa pertamamu. Pasang dari [python.org/downloads](https://www.python.org/downloads/), lalu coba interpreter interaktifnya.

Setelah itu, baca [tutorial resminya](https://docs.python.org/3/tutorial/) dan belajar membuat lingkungan virtual lewat `python -m venv`. Kalau sudah nyaman, lanjut ke `asyncio`, type hints, dan build free-threaded.

## Alternatif

- **Go:** statically typed dan dikompilasi ke kode mesin, sedangkan Python dijalankan lewat interpreter.
- **Ruby:** situs resminya menonjolkan kemudahan menulis dan membaca kode, dengan paket bernama gem, sedangkan Python memakai PyPI.
- **JavaScript:** dipakai 66% responden Stack Overflow Developer Survey 2025, lebih banyak daripada Python (57,9%).
